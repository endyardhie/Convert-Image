# Bundled components

Convert Image is distributed under the MIT license. Its Windows package also
contains Python, Tcl/Tk, Pillow and its image libraries, ReportLab, pypdf,
charset-normalizer, and the PyInstaller runtime. Their redistribution notices
are included in this directory and the application runtime directory.

The AVIF executables come from the official AOMediaCodec/libavif v1.4.2 Windows
release. That archive is pinned by SHA-256 in build.ps1. Notices for libavif,
libaom (including the AOM patent license), dav1d, libyuv, libjpeg-turbo, libpng,
libsharpyuv, and zlib are included here. Upstream source and build details:

- https://github.com/AOMediaCodec/libavif/tree/v1.4.2
- https://github.com/python/cpython
- https://github.com/tcltk/tk
- https://github.com/python-pillow/Pillow
- https://github.com/py-pdf/pypdf
- https://www.reportlab.com/
- https://github.com/pyinstaller/pyinstaller

These components remain subject to their respective licenses.
