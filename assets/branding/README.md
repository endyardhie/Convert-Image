# Identitas visual Nemo Convert Image

Aset logo dan banner untuk halaman proyek, dokumentasi, serta materi pengenalan Nemo Convert Image.

| Aset | File | Ukuran | Latar |
| --- | --- | --- | --- |
| Logo / ikon | [logo.png](logo.png) | 1254 × 1254 px | Transparan |
| Banner GitHub | [banner.png](banner.png) | 1983 × 793 px | Putih–mint |

Identitas memakai kartu gambar bertumpuk dan dua panah konversi, dengan warna hijau zamrud, teal, serta aksen mint. Tidak menggunakan karakter manusia atau hewan.

Banner menampilkan format hasil yang didukung aplikasi: **AVIF, JPG, PDF, PNG, dan WebP**.

Pertahankan rasio asli dan ruang di sekitar logo. Gunakan PNG transparan untuk latar terang maupun gelap, dan banner untuk area lebar seperti bagian atas README.

Kedua aset dibuat khusus untuk proyek ini dengan bantuan generasi gambar AI dan mengikuti [lisensi proyek](../../LICENSE).
